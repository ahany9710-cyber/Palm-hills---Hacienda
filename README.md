# Palm Hills — Hacienda Ras El Hekma

Landing page for **Hacienda Ras El Hekma** (Palm Hills, North Coast).

- **Live:** [hacienda-ivory.vercel.app](https://hacienda-ivory.vercel.app)
- **Repo:** [github.com/ahany9710-cyber/Palm-hills---Hacienda](https://github.com/ahany9710-cyber/Palm-hills---Hacienda)

## Tech Stack

Next.js 16 (App Router), TypeScript, static prototype HTML/CSS/JS, Formspree for leads.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project Structure

```
app/route.ts              # Serves the main landing (public/prototype/index.html)
public/prototype/         # Landing HTML, CSS, and JS
content/projects/         # Hacienda + sister-project content
public/hacienda/          # Brochure images and logos
```

## Deploy

Push to `main` on this repo — Vercel auto-deploys from [Palm-hills---Hacienda](https://github.com/ahany9710-cyber/Palm-hills---Hacienda).
